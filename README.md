# Online-E-Ticketing-System
# 🎫 Online E-Ticketing System

A web-based ticket booking system that allows users to register, log in, search for events, book tickets, make payments, and download e-tickets.

## ✨ Features

- User Registration & Login
- Event Search
- Online Ticket Booking
- Secure Payment Process
- Download E-Tickets
- User Profile Management
- Admin Dashboard

## 🛠️ Tech Stack

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/Harsha-Vardhan-1234/Online-E-Ticketing-System.git
```

Move the project to the XAMPP `htdocs` folder.

Start **Apache** and **MySQL** using XAMPP.

Import the database into **phpMyAdmin**.

Open your browser and visit:

```
http://localhost/Online-E-Ticketing-System
```

## 📌 How It Works

1. Register a new account.
2. Log in to the system.
3. Browse available events.
4. Select an event and book tickets.
5. Complete the payment process.
6. Download or view the generated e-ticket.
